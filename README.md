# Growify Digital — Marketing Website

A responsive digital marketing agency website built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Responsive desktop and mobile layout
- SEO, social media, paid advertising and web design service sections
- About, project and contact sections
- Mobile navigation and demo contact-form interaction

## Run locally
Open `index.html` in your browser. No build tools are required.

## Deploy on Vercel
Import this GitHub repository into Vercel. Choose **Other** as the framework preset, leave the build command empty, and set the output directory to `.`.

## Customize
Replace the sample brand name, email address and copy with your business details. The contact form is a front-end demo and needs an email or CRM integration to receive enquiries.
